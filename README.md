# Black-Jack-Game-Project
A console-based Blackjack game built using Python, implementing core game mechanics such as card shuffling, dealing, player vs dealer logic, score calculation, and win/lose conditions. This project demonstrates the use of control structures, functions, and basic object-oriented programming concepts.

📌 Features
🎴 Random card dealing system
👤 Player vs Dealer gameplay
🧮 Automatic score calculation
♠️ Ace value handling (1 or 11)
⚖️ Win, Lose, and Draw conditions
💻 Simple and interactive command-line interface

🛠️ Tech Stack
Language: Python
Concepts Used:
Conditional statements
Loops
Functions
Random module

🎮 How to Play
The game starts by dealing two cards to both the player and the dealer.
The player can choose to:
Hit → Take another card
Stand → End their turn
The dealer follows predefined rules (hits until reaching a certain score).
The winner is decided based on the total score:
Closest to 21 wins
Going above 21 results in a bust
